# 🎮 Number Guessing Game

A simple Python command-line game where the player tries to guess a randomly generated number within a limited number of attempts. This project was originally created to practice Python fundamentals and will later be expanded with a number of gameplay features!

## 🚀 Features
- attempts limits
- input validation
- score tracking
- random number generation

## 🧠 Concepts Used
- Python programming fundamentals
- input validation
- error handling
- modular project organization
